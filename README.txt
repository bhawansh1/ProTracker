================================================================================
PROTRACKER - PROJECT MANAGEMENT SYSTEM
================================================================================

1. OVERVIEW
ProTracker is a full-stack web application designed for teams to manage projects,
assign tasks, and track progress with Role-Based Access Control (RBAC).

2. ARCHITECTURE
The system follows a classic Client-Server architecture:

- FRONTEND: React (Vite) + TypeScript + Vanilla CSS
  - Responsible for UI/UX and state management.
  - Communicates with Backend via REST API (Axios).
  
- BACKEND: Node.js + Express + TypeScript + Prisma ORM
  - Handles authentication, business logic, and database queries.
  - Uses JWT for secure session management.
  
- DATABASE: PostgreSQL (via Docker) / SQLite (for demo)
  - Stores relational data for users, projects, and tasks.

3. APPLICATION FLOW
-------------------
A. AUTHENTICATION
   - User signs up as 'ADMIN' or 'MEMBER'.
   - System hashes password (bcrypt) and stores user.
   - User logs in and receives a JWT token.

B. DASHBOARD
   - Fetches real-time stats (Total Projects, Tasks, Completion %).
   - Identifies and alerts on Overdue Tasks based on due dates.

C. PROJECT MANAGEMENT
   - ADMINs can create projects.
   - Owners can add team members via their email addresses.
   - Projects list shows overview and task count.

D. TASK MANAGEMENT
   - Users create tasks inside projects.
   - Tasks are assigned to specific team members.
   - Status updates (To Do -> In Progress -> Completed) reflect globally.

4. DATABASE SCHEMA (RELATIONSHIPS)
----------------------------------
- USER: Basic profile + Role.
- PROJECT: Owned by one USER, has multiple TEAMMEMBERS and TASKS.
- TEAMMEMBER: Junction table linking USERS to PROJECTS with specific roles.
- TASK: Belongs to one PROJECT, assigned to one USER.

* Relationships:
  - User -> Project (1:N - Owner)
  - User -> TeamMember (1:N)
  - Project -> TeamMember (1:N)
  - Project -> Task (1:N)
  - User -> Task (1:N - Assignee)

5. HOW IT WORKS (TECH STACK)
----------------------------
- Authentication: JWT (JSON Web Tokens).
- Security: Role-Based Access Control (RBAC) middleware protects sensitive routes.
- Styling: Custom Vanilla CSS variables for a premium, light-themed look.
- API: RESTful endpoints structured by resource (Auth, Projects, Tasks, Dashboard).
- Data Safety: Prisma ORM ensures type-safety between the DB and Backend.
